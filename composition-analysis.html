4. The Key Tension

In a traditional codebase, duplication → extract shared utility.

In a composition pattern codebase, duplication across namespaces → extract the lowest-level primitive that makes both namespaces unnecessary boilerplate.

In a well-composed codebase, structural similarity in different contexts is the point, not a bug. The machine must learn when to stay quiet.

The suggestor needs a composition-awareness parameter — when toggled on, "extract primitive" suggestions replace "collapse duplicate" suggestions, barrel exports and namespace wrappers get skipped, and the entropy score thresholds get recalibrated.
